# SAP ERP Developer Portfolio

SAP 프로젝트와 학습·교육 경험을 바탕으로 업무 프로세스 이해와 개발 역량을 정리합니다.

## 주요 내용

1. **SAP E2E 경험**: SD · MM · PP · FI/CO 프로세스 연계와 통합 검증
2. **ABAP 개발**: Report · Screen · CBO 및 외부 API 연계 경험
3. **PM 경험**: 두 차례 SAP 팀 프로젝트의 일정·역할·모듈 간 의존성 관리
4. **개발 역량 확장**: S/4HANA · RAP · CDS · OData 학습 및 구현 경험

세부 내용은 `index.html`에 정리되어 있습니다.
