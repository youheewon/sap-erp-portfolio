# SAP ERP Developer Portfolio

현대오토에버 SAP ERP 신입 지원을 위한 포트폴리오 Repository입니다.
SAP 프로젝트와 학습·교육 경험을 바탕으로 업무 프로세스 이해와 개발 역량을 정리합니다.

## 주요 내용

1. **SAP E2E 경험**: SD · MM · PP · FI/CO 프로세스 연계와 통합 검증
2. **ABAP 개발**: Report · Screen · CBO 및 외부 API 연계 경험
3. **PM 경험**: 두 차례 SAP 팀 프로젝트의 일정·역할·모듈 간 의존성 관리
4. **개발 역량 확장**: S/4HANA · RAP · CDS · OData 학습 및 구현 경험

세부 내용은 `index.html`에 정리되어 있습니다.

## 파일 구조

```text
.
├── index.html
├── style.css
├── README.md
└── .gitignore
```

별도 빌드나 패키지 설치가 필요 없는 HTML/CSS 페이지입니다.
다운로드한 폴더에서 `index.html`을 브라우저로 열어 확인할 수 있습니다.
스타일시트는 같은 폴더의 `style.css`를 상대 경로로 참조합니다.

- 채용용 PDF는 준비 중이며 `portfolio.pdf`는 포함하지 않습니다.
- PDF 버튼 2개는 비활성화되어 있어 없는 파일로 이동하지 않습니다.
- GitHub 프로필 링크는 `https://github.com/youheewon`입니다.
- 이름은 `유희원`, 이메일은 `heewon3514@naver.com`으로 반영했습니다.
- 사용자에게 확인받은 SAP 자격증 명칭을 `index.html`에 반영했습니다.
- 자격증 PDF는 `certificates/` 경로를 사용하며, 파일이 존재할 때만 Certificate 링크가 표시됩니다.

## GitHub Pages 활성화 전 확인

- 현재 `index.html` 푸터에 공개용 이름과 이메일이 반영되어 있습니다.
- 자격증 Certificate와 페이지 표기가 최종적으로 일치하는지 확인합니다.
- 프로젝트 설명·역할·기술 스택이 실제 수행 범위와 일치하는지 최종 확인합니다.
- 완성된 PDF를 추가할 때 서버 주소/IP, 계정·비밀번호·접속정보, 학교 내부 시스템 정보, API Key, 팀원 개인정보 및 기타 비공개 정보를 검사합니다.
- PDF 공개 준비가 끝나면 루트에 `portfolio.pdf`를 추가하고 비활성 버튼 2개를 해당 파일 링크로 교체합니다. PDF 안내 문구도 함께 수정합니다.
- PDF 준비 전 Pages를 활성화하는 경우에는 현재의 `준비 중` 표시를 유지할 수 있습니다.

현재 작업 범위는 Repository 파일 정리까지이며, GitHub Pages 활성화는 별도로 진행합니다.
