RAP SD O2C

기존 SAP GUI에서 T-code를 오가던 SD 업무를 SO Request와 OTC Monitor 두 Fiori Elements 앱으로 구성한 개인 프로젝트입니다.

CDS ViewRAP Managed DraftRAP ActionFiori ElementsOData / SOAP API

Process / Architecture

SO Request→OTC Monitor→Delivery→Picking / PGI→Billing

My Role / Implementation

  • SO Request: Header와 여러 Item의 Draft를 관리하고 표준 Sales Order 생성
  • OTC Monitor: Header 조회 및 Item별 후속 문서 상태 확인
  • Instance Feature로 실행 가능한 Action 제어
  • OData로 Delivery 및 Picking/PGI, SOAP API로 Billing 연계

Issue / Design Decision

API 호출 단계에서 HTTPS 인증서 호스트명 불일치 문제를 확인했습니다. 학교 개발 서버 내부의 HTTP Destination으로 호출 방식을 변경해 기능을 구현했습니다. 실제 HTTPS 설정 문제는 별도 운영 제약으로 남아 있습니다.
