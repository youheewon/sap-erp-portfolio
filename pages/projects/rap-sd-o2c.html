RAP SD O2C

SAP GUI에서 여러 T-code로 수행하던 SD 업무를 두 개의 Fiori Elements 앱으로 재구성했습니다. Sales Order 생성은 SO Request에서, 주문 현황 조회와 Delivery부터 Billing까지의 후속 처리는 OTC Monitor에서 담당합니다.

CDS View RAP Managed Draft RAP Action Fiori Elements OData / SOAP API

Fiori Elements Apps

APP 01OTC Monitor

List Report에서 Sales Order를 조회하고, Object Page의 Item별 문서 상태를 확인합니다. 선택한 Item에 대해 Delivery, Picking/PGI, Billing Action을 실행합니다.

APP 02SO Request

RAP Managed Draft 기반의 별도 Business Object입니다. Header와 여러 Item을 작성하고 SubmitSalesOrder Action으로 SAP 표준 Sales Order를 생성합니다.

CHAPTER 02 / SO REQUEST

Sales Order 생성용 RAP Draft 앱

Sales Order 생성 기능은 OTC Monitor에서 분리했습니다. SO Request에서는 하나의 Header와 여러 Item을 작성하고 Draft로 관리합니다. SubmitSalesOrder Action을 실행하면 SAP 표준 Sales Order가 생성되며, 해당 주문은 OTC Monitor의 조회 대상에 포함됩니다. 두 앱 사이에 자동 화면 전환을 구현한 것은 아닙니다.
