ABAP 렌터카

렌터카 차량 관리 정보를 조회하는 ABAP 개인 프로젝트입니다. 테이블 관계를 설계하고 Selection Screen, ALV Grid, 조건별 입력 검증, 이벤트별 상세조회 기능을 구현했습니다.

ABAP DictionaryReport / Selection ScreenSQL JOINALV GridField Catalog / LayoutALV Events

My Role / Implementation

  • 차량·예약·회원 등 테이블 관계 설계
  • 차량관리 Report, 조건별 검색 및 입력 검증
  • ALV Field Catalog, Layout, 색상과 크기 조절
  • Toolbar, Double Click, Hotspot, Context Menu 이벤트 구현

Project Scope

이 프로젝트는 차량 관리 정보를 조회하는 ABAP Report 개발 사례입니다. 예약 현황과 회원 정보를 조회하는 기능을 구현했으며, 예약 생성이나 결제를 처리하는 프로그램은 아닙니다.
