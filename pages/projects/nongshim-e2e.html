PROJECT 01 · 팀 프로젝트 - 6인 · PM

농심 E2E

농심의 공개 자료를 바탕으로 식품 제조업의 업무 흐름을 설계한 학내 SAP E2E 프로젝트입니다. 실제 농심에 구축한 시스템이 아니며, SAP Standard 및 Configuration을 중심으로 진행했습니다.

SAP StandardIMG ConfigurationSD · MM · PP · FI/CO 연계Batch / SLEDABAP CBO

My Role / Implementation

  • PM으로 프로젝트 목표·일정 및 모듈 간 인터페이스를 관리
  • SD · MM · FI · CO Configuration 및 표준 트랜잭션 실행·검증
  • 공통 Master Data 구성과 E2E 통합 테스트 수행
  • 배송 현황 CBO와 외부 지도 API 연계 구현

Issue / Design Decision

첫 프로젝트에서 CBO로 업무를 구현한 경험을 토대로, 이번에는 SAP Standard Transaction과 Configuration을 중심으로 업무 흐름을 구성했습니다. 자재 초기 입고에서는 Material Ledger 관련 설정을 점검하고 해당 Valuation Area의 설정을 조정해 입고와 자재 평가를 정상화했습니다.
