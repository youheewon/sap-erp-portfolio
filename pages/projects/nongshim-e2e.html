PROJECT 01 · 팀 프로젝트 - 6인 · PM

농심 E2E

농심의 공개 자료를 바탕으로 식품 제조업 시나리오를 설계한 학내 SAP E2E 프로젝트입니다. 실제 농심에 구축한 시스템은 아닙니다. SAP Standard와 Configuration을 중심으로 구현하고, 필요한 일부 업무는 ABAP CBO로 보완했습니다.

SAP StandardSD / MM / FI / CO ConfigurationPP 연계Batch · SLEDABAP CBOPM · E2E 통합 테스트

My Role / Implementation

  • PM으로 프로젝트 기획·일정과 모듈 간 연결을 관리
  • SD·MM·FI·CO Configuration 및 표준 트랜잭션 실행·검증
  • 공통 Master Data와 E2E 통합 테스트 진행
  • POD 프로세스 기획 및 핵심 ABAP 로직 구현 (Batch Job은 팀원 담당)
  • Delivery Management CBO와 지도·번역 API 연계 개발

Project Approach

앞선 CBO 중심 E2E 프로젝트와 달리, 표준 트랜잭션과 IMG 설정을 우선 적용했습니다. SD, PP, MM, FI/CO를 업무 흐름으로 연결하고 배송 현황 및 POD처럼 필요한 부분만 CBO로 보완했습니다.

CHAPTER 09

09. 일정 지연과 문제 해결

개발 일정이 지연됐을 때 원인을 확인하고 범위를 무작정 축소하지 않도록 대응했습니다. 다음 내용은 발표자료에 별도 오류 캡처가 없는 개인 수행 경험이므로 사진이 아니라 설명으로 구분합니다.

Material Ledger로 지연된 초기 자재 입고

입고 과정에서 Material Ledger 관련 오류로 일정이 약 2주 지연됐습니다. 원인을 CO 자체의 문제로 단정하기보다 SAP Help Portal과 관련 사례를 확인했습니다. 이후 해당 Valuation Area의 설정을 수정하고 Material Ledger를 활성화해 입고와 자재 평가를 정상화했습니다.

PM의 일정 관리와 통합 테스트

전체 프로세스와 앞뒤 모듈의 의존성을 점검하면서 지연된 업무 영역을 직접 보완했습니다. 표준 트랜잭션 실행 결과를 후속 모듈에서 확인하고, 누락된 설정과 데이터 연계 문제를 해결하는 데 집중했습니다.

이 문제 해결 과정의 오류 화면·일정 수정 이력은 현재 발표자료에 포함돼 있지 않습니다. 실무 운영 사례가 아닌 학내 프로젝트의 개발 경험을 설명합니다.
