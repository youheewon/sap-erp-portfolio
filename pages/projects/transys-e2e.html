PROJECT 02 · 팀 프로젝트 - 6인 · PM

현대트랜시스 E2E

현대트랜시스의 공개 자료를 바탕으로 자동차 부품 제조업의 SAP E2E 프로세스를 설계한 학내 프로젝트입니다. 표준 구축 사례가 아닌 ABAP CBO 중심의 구현 프로젝트입니다.

ABAP Report / ScreenSD / FI CBOE2E 프로세스 설계Input CheckPM / 일정 관리

My Role / Implementation

  • PM으로 모듈별 업무 흐름, 공통 데이터 및 프로그램 사양서 정리
  • 담당자별 최초 배정과 별개로 일정 지연 영역의 SD·FI CBO를 직접 개발·보완
  • Sales Order의 고객·납기일·자재·수량 입력 검증 구현
  • 후속 모듈이 사용할 데이터를 고려해 통합 테스트 수행

Issue / Design Decision

프로그램을 개별 화면으로만 개발하지 않고 각 단계의 입력값과 다음 모듈로 전달될 데이터를 정리해 사양서를 작성했습니다. Sales Order 생성 단계에는 유효하지 않은 값이 후속 프로세스로 전달되지 않도록 Input Check와 오류 메시지를 적용했습니다.
