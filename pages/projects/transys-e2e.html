PROJECT 02 · 팀 프로젝트 - 6인 · PM

현대트랜시스 E2E

현대트랜시스의 공개 자료를 바탕으로 자동차 부품 제조업의 업무 프로세스를 조사한 학내 SAP E2E 프로젝트입니다. 실제 현대트랜시스에 구축한 시스템이 아니며, ABAP CBO 중심으로 설계·개발했습니다.

ABAP Report / ScreenSD·FI CBOSD·MM·PP·FI 통합Input CheckPM / 일정 관리

My Role / Implementation

  • PM으로 E2E 프로세스 설계, 일정 및 개발 기준 관리
  • 모듈 간 입력값과 전달 데이터를 정의하고 프로그램 사양서 작성
  • SD·FI CBO 개발과 Sales Order 입력값 검증 구현
  • 일정이 지연된 기능을 보완하고 모듈 연계 테스트 진행

Project Approach

기업의 공장·생산품·공급망·고객 데이터를 공개 자료로 조사한 뒤 SAP 조직과 업무 흐름을 설계했습니다. 모듈별로 개발한 프로그램이 문서를 주고받을 수 있도록 입력값과 후속 데이터를 정리했습니다. MM·PP 화면은 팀 전체 성과이며 개인 직접 개발 범위와 구분했습니다.
